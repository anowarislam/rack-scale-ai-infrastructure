# Choose one specialty, then finish its operating loop

Each learner completes one lane as part of [G3-E06](../curriculum/18-specialty-integration.md). The lane is a context for one narrow intervention. It is not a survey of every technology in the title. Work on the same intervention during months 13-18, with execution concentrated in months 17-18; do not add a second specialty to the mandatory workload.

| Packet | Single intervention | Minimum evidence for the named claim |
|---|---|---|
| [Rack lifecycle](rack-lifecycle.md) | Require current, complete qualification evidence before promotion | L0 for validator logic; supervised L3 for a physical rack workflow claim |
| [Performance](performance.md) | Stagger checkpoint starts for one fixed workload | L2 measured workload for multi-node improvement; L0 analysis is a lower claim |
| [Workload platform](workload-platform.md) | Add one tenant GPU admission cap | Actual primary platform for policy behavior; CPU substitute cannot establish GPU placement |
| [Fleet automation](fleet-automation.md) | Bind retry intent to current state generation | L0 runnable state machine for logical guarantees; real integration remains separate |

The source of a number matters. Mark every result as observed, independently derived, synthetic, or unknown. A failed performance hypothesis with correct recovery is a valid experiment; it does not become a performance improvement. A policy that reduces risk but delays work has a tradeoff to measure.

All packets follow characterize -> intervene -> validate -> recover -> operationalize. Use the [evidence template](../assessments/evidence-template.md), preserve original failures, and record exact versions and topology. A peer must be able to replay the local evidence. Optional hardware execution requires the course lab authorization conditions; a lesson is never authorization to alter a production system.

The specialty contributes the technical anchor for one [role-family capstone](../practicum/capstones/README.md). Course-observed leadership and longitudinal management evidence remain distinct.
